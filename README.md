# KidPad 兒童學習練習台

給幼稚園～小一小朋友用的練習台。左邊是主功能區（各種練習項目），右邊是內容區，
點左邊哪個功能，右邊就換成對應的畫面。目前有**筆劃練習**、**算術練習**、**英文練習**、**注音符號**、**時鐘**、**認識錢幣**六個模組。

純前端、沒有後端、不用建置（no npm、no build），丟到 GitHub Pages 就能給所有人開連結使用。

---

## 怎麼打開

### 方法一：直接開線上版（最簡單）

部署完成後就是這個網址（把帳號換成你的）：

```
https://<你的GitHub帳號>.github.io/<repo名稱>/
```

手機／平板開這個網址，選「加入主畫面」，就會像 App 一樣有圖示，也能離線用。

### 方法二：在自己電腦跑

雙擊 **`start.bat`**（需要有 Python），或在專案資料夾執行：

```bash
python -m http.server 8765
```

然後開 <http://127.0.0.1:8765/>

> ⚠️ 不能直接雙擊 `index.html`。這個專案用 ES Module，瀏覽器在 `file://` 底下會擋住模組載入，
> 一定要透過 http 開。`start.bat` 就是幫你做這件事。

## 目前的功能

### 筆劃練習

打開先看到關卡選單，分三個 Level：

| Level | 內容 |
|---|---|
| 1 · 基本筆劃 | 橫、豎、撇、點、捺、折、鉤、提，每個都有名字和「從左邊畫到右邊」這種說法 |
| 2 · 筆順規則 | 從上到下（三、二）、從左到右（川、州）、先橫後豎（十、干、土）、先撇後捺（人、八、大）、先外後內（月、日、同）；練到這些字時畫面會直接說出規則 |
| 3 · 常用字 | 我的名字（大人輸入一次）、筆劃少的字 37 字、生活常用字 34 字、動物和大自然 20 字 |
| 🎲 隨機練習 | 從上面全部混在一起抽 8 個，寫完自動再抽一批，想停再按「← 關卡」 |

| 功能 | 說明 |
|---|---|
| 看一次 | 慢速播放筆順動畫，一筆一劃示範 |
| 我來寫 | 淡灰色描紅底稿，用手指或滑鼠描；寫對一筆有音效＋🐼 跳一下，寫錯只會溫和提醒重來 |
| 完成獎勵 | 一個字寫完跳出星星，可以直接「下一個 →」接著練 |
| 練習紀錄 | 每張卡下面用星星顯示練過幾次，關卡卡片顯示 `3 / 8` 這種完成度 |

> 「乀」（捺）和「㇀」（提）在筆順資料庫裡查不到，所以這兩個筆劃改用「人」的第二筆、
> 「打」的第三筆來練，前面的筆劃會先畫好，小朋友只要描目標那一筆。

### 算術練習

打開先看到**關卡地圖**：一張地圖 5 關，每關 6 題，全部打完寶箱就會打開，解鎖下一張地圖。
完整的內容規劃見 [docs/CONTENT-PLAN.md](docs/CONTENT-PLAN.md)。

| 難度 | 內容 | 什麼時候出現 |
|---|---|---|
| Level 1 | 數一數、比大小、接數字（3、4、□、6） | 只在一關錯 2 題以上之後，下一關安靜地換成這種題 |
| Level 2 | 10 以內加減（純算式）：`5 ＋ 3 ＝ ?`、`9 － 2 ＝ ?` | 第 1 張地圖，也是起點 |
| Level 3 | 個位數進位加法（附**十格框**）、同樣的題目不給十格框 | 第 2 張地圖；或任何一關連對 3 題後臨時加難 |

> 題目的兩個運算元一律是個位數（1–9），所以不出「13 － 5」這種退位減法；答案可以是兩位數。
> **Level 2 以上不放可以數的圖案** —— 圖案直接畫出答案的話，小朋友會用數的而不是用算的。
> 圖案改成「同一題連錯兩次」才出現的提示，卡住時才給。
> 地圖上還有「🎲 隨機挑戰」：以個位數加減為主，**一直出題不結算**，想停再按「結束」，每答對 5 題一顆星。

| 互動 | 說明 |
|---|---|
| 答對 | 按鈕變綠、**星星粒子噴出來**、音效，0.8 秒後自動跳下一題 |
| 連對 | 連對 2 題冒出「連對 2！」，3 題以上換成 🔥 並且題目變難 |
| 答錯 | 只有淡出變灰＋輕晃＋柔和音，可以一直重選；不變紅、不打叉、不計時、不扣分 |
| 過關 | 回到地圖，🦊 蹦跳前進一格，星星從天上掉下來 |
| 星星 | 一關結束給 1 顆，全對給 2 顆，累積在左側選單的按鈕上 |

> 貼紙簿與獎章排在 S5。

### 英文練習

26 個字母小朋友都認得，所以 Level 1 的任務不是教字母，而是抓出還會混淆的那幾組。

| 難度 | 題型 | 怎麼進到下一級 |
|---|---|---|
| Level 1 · 認字母 | 大小寫配對（看 **B** 選 b/d/p）、聽音找字母、字母順序（A、B、□、D） | 連續兩輪全對就自動解鎖 Level 2 |
| Level 2 · 聽發音 | 聽單字選開頭字母（🔊 `_pple` → A）、看圖選字母（🍎 → A） | — |

> 每個字母配 2–3 個單字；聽單字題會把單字寫出來但遮住第一個字母，沒聽清楚也看得到題目。
> 右上角有「🎲 隨機模式」：兩級題型混在一起、**一直出題不結算**，每答對 5 題一顆星。

- 一輪 6 題，**前 4 題一定來自易混淆組**：b/d、p/q、M/N/W、i/j、u/v
- 發音用瀏覽器內建的 SpeechSynthesis，沒有音檔；Windows 與 iPad 都是系統內建語音，離線也會唸
- **唸的是整個單字（apple）不是音素**，合成語音唸 /æ/ 會失真到聽不懂
- 沒有英文語音的裝置：喇叭按鈕不會出現，Level 2 自動只出看圖選字母，不會按了沒反應

### 注音符號

小一上就要學。注音符號在筆順資料庫裡查不到，所以**不做描寫，只做認讀**。

| 難度 | 題型 |
|---|---|
| Level 1 · 記順序 | ㄅ ㄆ □ ㄈ，少了哪一個 |
| Level 2 · 看圖選注音 | 🐱 貓咪 → 哪個注音開頭 |
| Level 3 · 反過來找 | 給 ㄓ，選出「🐷 豬」 |

### 時鐘

時鐘是 SVG 畫的，時針會跟著分針移動（3 點半的短針在 3 和 4 中間）。

| 難度 | 題型 |
|---|---|
| Level 1 · 整點 | 長針指 12 |
| Level 2 · 半點 | 長針指 6 |
| Level 3 · 混在一起 | 干擾選項一定包含「同一個鐘點的另一半」 |

### 認識錢幣

台灣的 1 / 5 / 10 / 50 元硬幣，也是 SVG 畫的（大小與顏色照實際硬幣區分）。

| 難度 | 題型 |
|---|---|
| Level 1 · 這是幾元 | 一枚硬幣 |
| Level 2 · 數錢 | 2–4 枚加起來幾元（接上他已經會的加法） |
| Level 3 · 比多少 | 兩堆硬幣，哪一邊比較多 |

> 這三個模組共用 `lib/level-module.js`：連續兩輪全對升一級，右上角都有「🎲 隨機模式」。

### 夥伴角色與回饋

每個模組旁邊有一隻小動物：筆劃 🐼、算術 🦊、英文 🐧。答對／寫對一筆會跳一下，
答錯會歪頭並冒出說話泡泡；同一題連錯兩次，正確答案會開始呼吸發光。

畫面上的中文提示會**用語音唸出來**，這個年紀還不太會讀字，用聽的比較跟得上：

| 時機 | 會唸什麼 |
|---|---|
| 點左側模組、關卡、字卡 | 點到什麼就唸什麼（「算術練習」「第 1 關」「橫」） |
| 第一次進到模組 | 「這裡是算術練習，選一關開始」 |
| 題目出現 | 「7 減 3 等於多少」「橫，從左邊畫到右邊」 |
| 答錯、拿到星星、完成一輪 | 「再想想看」「數數看這些圖案」「全部答對，拿到 2 顆星」 |
| **發呆 15 秒** | 夥伴冒泡泡說「選一個答案看看」／「按綠色的按鈕開始寫」，同時**該按的按鈕會脈動** |

沒有中文語音的裝置會自動安靜略過，畫面提示照常。

## 怎麼新增一個練習模組

**只要兩件事**，不用去改 `app.js`：

**第 1 步**：在 `modules/` 建一個檔案，例如 `modules/music.js`，預設匯出這個介面：

```js
let built = false;

export default {
  id: 'music',        // 唯一代號
  title: '音樂練習',   // 左側選單和頁籤上的名字
  icon: '🎵',         // 一個 emoji

  mount(container) {
    // container 是這個模組專屬的 <section>，第一次進來時建畫面
    if (built) return;          // 切回來時 DOM 還在，不要重建
    container.innerHTML = `<h2>音樂練習</h2>`;
    built = true;
  },

  unmount() {
    // 切走時被呼叫：停動畫、存檔。DOM 會被保留，狀態不會遺失
  },
};
```

**第 2 步**：在 `modules/index.js` 的陣列加一行：

```js
{ id: 'music', title: '音樂練習', icon: '🎵', load: () => import('./music.js') },
```

存檔重整，左側選單就多一個項目了。（加 `soon: true` 會在按鈕上標「準備中」。）

## 檔案結構

```
index.html              版面骨架（左功能區 + 右內容區）
styles.css              全部樣式
app.js                  主容器：畫選單、管 panel、切模組（不含任何模組細節）
modules/
  index.js              ★ 模組註冊表，新增模組改這裡
  stroke.js             筆劃練習
  math.js               算術練習
  english.js            英文練習
  bopomo.js             注音符號
  clock.js              時鐘（SVG 鐘面）
  money.js              認識錢幣（SVG 硬幣）
lib/
  storage.js            localStorage 封裝
  sound.js              Web Audio 合成音效（不需要音檔）
  hanzi-data.js         筆順資料載入：瀏覽器快取 → 本地 vendor → CDN
  quiz-ui.js            選擇題骨架（進度列／選項／答對答錯回饋／星星粒子／夥伴），算術與英文共用
  speech.js             英文與中文語音（SpeechSynthesis），沒有語音時安靜停用
  stars.js              星星總帳，左側選單的徽章看這裡
  level-module.js       分級選擇題模組的共用骨架（注音、時鐘、錢幣共用）
vendor/
  hanzi-writer.min.js   筆順函式庫（本機副本，不吃 CDN）
  hanzi-data/*.json     217 個字的筆順資料（基本筆劃、規則示範字、四組字表、常見姓名用字）
manifest.webmanifest    PWA 設定，可以「加入主畫面」
sw.js                   Service Worker，用過的內容會離線保留
deploy.bat / deploy.ps1 一鍵部署到 GitHub Pages
start.bat               在本機起伺服器並開瀏覽器
```

## 資料存在哪

全部在瀏覽器的 localStorage，不會上傳到任何地方：

| key | 內容 |
|---|---|
| `kidpad.stroke.records` | 每個字練過幾次、最後練習時間 |
| `kidpad.stroke.strokes` | 每個基本筆劃練過幾次 |
| `kidpad.stroke.lastLesson` | 上次進的關卡 |
| `kidpad.child.name` | 小朋友的名字（「我的名字」關卡用） |
| `kidpad.lastModule` | 上次開的模組 |
| `kidpad.stars` | 每個模組累積的星星數 |
| `kidpad.math.progress` | 算術練習的地圖等級、過關數、難度調整 |
| `kidpad.english.progress` | 英文練習的等級與連續全對輪數 |
| `kidpad.bopomo.progress` `kidpad.clock.progress` `kidpad.money.progress` | 注音／時鐘／錢幣的等級與連續全對輪數 |
| `kidpad.char.<字>` | 該字的筆順資料快取（讓下次離線也能練） |

## 離線

`vendor/hanzi-data/` 裡附的 174 個字完全離線可用。
不在裡面的字，第一次練需要連網（會自動去 CDN 抓），抓過一次之後就存在瀏覽器裡，之後離線照練。
